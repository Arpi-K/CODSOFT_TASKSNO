# CodSoft Data Analytics Internship

This repository contains the projects completed as part of my **CodSoft Data Analytics Virtual Internship**. The internship projects cover data cleaning, exploratory data analysis, and data visualization using Python, Pandas, Matplotlib, Seaborn, and Power BI.

## 📌 Projects

### Task 1 — Data Cleaning and Preprocessing

**Project: E-commerce Delivery Analysis**

**Tools:** Python, Pandas, NumPy

This project focuses on cleaning and preprocessing an e-commerce delivery dataset to prepare it for further analysis.

**Key activities:**

* Identified and handled missing values
* Detected and removed duplicate records
* Standardized inconsistent categorical values
* Corrected data types and invalid values
* Prepared a clean dataset for analysis

**Dataset:** E-commerce_Delivery_Analytics

---

### Task 2 — Exploratory Data Analysis

**Project: Airbnb Data Listings Analysis**

**Tools:** Python, Pandas, Matplotlib, Seaborn

This project performs exploratory data analysis on Airbnb listing data to understand pricing, accommodation types, locations, reviews, availability, and host characteristics.

**Key analysis:**

* Analyzed listing distribution by room type and neighbourhood
* Examined Airbnb pricing patterns
* Compared prices across room types and locations
* Analyzed customer review ratings
* Studied listing availability and minimum stay requirements
* Investigated relationships between price, reviews, and availability
* Identified potential outliers and unusual patterns
* Derived business-oriented insights from the data

**Dataset:** Airbnb_Open_Data

---

### Task 3 — Data Visualization and Dashboard

**Project: HR Analytics Dashboard**

**Tools:** Power BI

This project focuses on transforming HR data into an interactive dashboard to understand employee attrition and workforce trends.

**Dashboard analysis includes:**

* Employee attrition
* Department-wise workforce analysis
* Job role analysis
* Employee demographics
* Job satisfaction
* Work experience
* Salary-related analysis
* Key HR performance indicators

**Key objective:**
To provide an interactive visual summary of employee trends and attrition patterns that can support data-driven HR decision-making.
